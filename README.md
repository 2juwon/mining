# 한판 광산

마우스를 바위 위에 올려 두면 곡괭이가 저절로 캐는 판타지 광산 게임(PC용). 바위가 수십 개에서 끝 무렵 한 화면에 수천 개까지 늘어나고, 폭발이 연쇄로 번지며 와르르 깨져요(WebGL). 캔 광석으로 스킬 트리를 열고 곡괭이를 만들어 돌층부터 별철층까지 내려가, 가장 깊은 곳의 **광산의 심장**을 깨면 클리어. 새 게임부터 클리어까지 걸린 시간으로 랭킹을 매겨요.

- 게임: https://2juwon.github.io/mining/
- 랭킹 서버: https://mining.2juwon.workers.dev (관리 페이지 `/admin`)
- 클래식(바위 수십 개 예전 판, 따로 저장·랭킹): https://2juwon.github.io/mining/classic/ — 브랜치 `classic-v1`에 그때 소스
- 광산 실험실(바위 수천 개 시험판): https://2juwon.github.io/mining/lab/

## 게임 구성

- **채굴**: 한 판 12초부터. 마우스 고리 안의 바위를 정해진 간격으로 때림. 치명타·번개(다른 바위로 튐)·폭발(주변 바위)·시간의 모래(+0.5초, 한 판에 채굴 시간의 절반까지)
- **바위 수천 개**: 바위 최대 수 처음 16개 → '빽빽한 광맥' I·II·III(+8·+110·+480/레벨)와 카드 '광맥 증식'(+6%)으로 끝 무렵 3,000~5,000개. 채굴장은 바위 수에 맞춰 넓어지고(√(바위/70)배) 화면은 멀리서 봐서 바위가 작아짐. 고리도 함께 넓어짐. 다 깨도 꽉 차기까지 처음 4초(스킬로 빨라짐)
- **연쇄 폭발**: 깨질 때 폭발 확률로 터지고, 폭발로 깨진 바위가 또 터질 확률은 대마다 '연쇄 이어짐'(처음 45%, 카드 '도화선'으로 오름, 최대 85%)을 곱해 약해짐. 0.06~0.11초씩 늦게 터져 물결처럼 번짐. 광산의 심장은 폭발·번개에 다치지 않고 곡괭이로만
- **광석 10가지**: 돌 → 구리 → 철 → 은 → 금 → 수정 → 미스릴 → 아다만트 → 흑요석 → 별철
- **스킬 트리**: 가운데에서 나선으로 뻗는 안개 낀 지도. 광맥 기둥 + 깊이마다 양옆 가지 41칸 + 광석 숙련 10칸 + 새 능력 8칸 + 갈림길 3쌍
- **새 능력**(가지 바깥 끝, 각 3단계): 콤보 채굴(구리, 연달아 많이 깰수록 광석 최대 +75%) · 보물 바위(철, 5배 단단하지만 광석 30개분·보석) · 광맥 줄기(은, 같은 광석이 줄지어 생기고 하나 깨면 줄 전체) · 연금술(금, 한 단계 위 광석) · 소용돌이(수정, 둘레 바위를 고리 쪽으로) · 꼬마 광부(미스릴, 돌아다니며 캠) · 유성우(아다만트, 한 판에 유성 2~6개) · 마지막 불꽃(흑요석, 남은 3초 느려지고 공격력 오름). 꼬마 광부·유성·폭발·번개는 심장을 못 때림
- **갈림길**(둘 중 하나, 한 번 정하면 그 게임에선 못 바꿈): 은 — 폭발 광부/번개 광부, 미스릴 — 광맥 장인/보물 사냥꾼, 흑요석 — 유성 소환사/광부 대장
- **곡괭이 11가지**: 광석으로 만들고 보석으로 강화(레벨마다 +15%, 최대 10)
- **재능 카드**: 레벨 업마다 3장 중 1장(보통·희귀·전설). 한 장마다 바위 체력 +4%
- **자동 광산**: 화면을 보는 동안과 창을 닫아 둔 동안(최대 8시간) 광석을 캠
- **광석 숙련**: 한 층 더 내려가면 지난 광석의 숙련이 열림. 레벨 끝없음, 그 광석으로만 값을 내고 레벨마다 공격력 +1.5%(숙련끼리 더함)
- **클리어**: 별철 광맥 뒤 「광산의 심장」(체력 900억, 판이 바뀌어도 이어짐)

## 랭킹

판마다 표가 따로예요(지금 판 = 2, 클래식 = 1, `/api/rank?v=2`). 새 게임을 시작하면 서버가 도전 번호를 주고 시작 시각을 적어 둠 → 심장을 깨는 순간 서버가 자기 시계로 걸린 시간을 잼 → 이름(8자)을 올림(7일 안, 한 번). 20분보다 빠르거나 40판 미만인 기록은 거절하고 의견함에 자동 신고. 게임은 브라우저에서 돌아가서 저장 내용을 고친 기록까지는 못 막으니, 이상한 기록은 관리 페이지에서 지움.

## 파일

- `src/engine.js` — 규칙 엔진 `MG` (상태는 JSON, 화면과 무관)
- `src/ui.html` — 화면(PixiJS 7.4.2 legacy로 그리는 채굴장, 스킬 트리, 곡괭이, 재능, 랭킹), 효과음은 WebAudio로 직접 만듦
- `build.js` — `index.html`(Pages, 서버 주소 포함)과 `dist/mine.html`(아티팩트, 서버 없음)을 만듦
- `config.json` — 랭킹 서버 주소
- `server/` — Cloudflare Workers + Durable Objects(Rank, Inbox)
- `test/rules.test.js` — 규칙 시험, `test/sim.js` — 자동 플레이로 진행 곡선 재기, `test/browser.py`·`test/online_browser.py` — 브라우저 시험, `server/test/rank.test.mjs` — 서버 시험

## 고치는 방법

```
node test/rules.test.js
node test/sim.js 8          # 균형을 바꿨으면 클리어 시간 확인 (잘하는 자동 플레이 약 30분)
node build.js               # index.html 다시 만들기 → 커밋
```

서버는 `main`에 `server/`가 바뀌면 GitHub Actions '서버 배포'가 올림(Secrets `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID`, 관리용 `ADMIN_KEY`). 로컬 시험은 `cd server && npx wrangler dev --var FAST_TEST:1 --var ADMIN_KEY:test` → `node test/rank.test.mjs`.

저장은 각자 브라우저에만(localStorage `hanpan-mine-v2`, 클래식은 `hanpan-mine-v1`). 브라우저 시험은 pixi 파일을 로컬로 대신 줌(`PIXI=…/pixi-legacy.min.js`).
